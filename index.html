The intent

Light is a material. So is code. I treat both like clay —

Building started small: a store, a food pipeline, a terminal tool. Every one taught the same lesson — interfaces are scenes, and scenes are stories told with motion. Three.js gives geometry a soul, GSAP gives time a rhythm, and PHP keeps the whole thing running while nobody watches. The result is work that feels lived-in: warm, weighty, impossible to ignore. Pragmatic by default, allergic to sloppy details, and a fast self-directed learner — I bridge real business needs into working code, not theory.

  • Built real-time procedural lighting & clay-shading sculpts in vanilla Three.js.
  • Engineered physics-based 3D scroll synchronization with sub-pixel camera poses.
02 2023 — 2024 Fullstack Systems

E-Commerce, POS & Routing Cores

Hand-crafted modular PHP backends — full e-commerce and point-of-sale flows without framework overhead. Relational SQL schemas, cart state engines, and Nginx rules tuned for ultra-low latency.

  • Implemented custom auth, cart state engines, checkout, and admin dashboards.
  • Designed normalized business data (3NF) and sub-120ms renders on low-cost VPS.
